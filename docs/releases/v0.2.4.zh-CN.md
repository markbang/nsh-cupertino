# nsh-cupertino 0.2.4

[English](v0.2.4.md)

非 Apple 平台上的设计字体：每个平台一份字体列表，iOS 的字距只在它为之设计的那款字体上生效。

## 变化

- **字体** —— `Theme` 在根视图上设置平台的字体列表，内部所有文字继承：Android 是
  Roboto、Noto Sans CJK SC 加系统兜底；Windows 是 Segoe UI Variable Text、微软雅黑 UI；
  Linux 是 Inter、Cantarell、DejaVu Sans；Web 以 `-apple-system` 优先。
  Apple 平台不指定：SF Pro（中文为苹方）正是这套字号为之设计的字体。
- **字距** —— `tokens::tracking(style)` 在 Apple 平台上取设计值，其它平台为 0。
  Roboto 与 Noto 自带字距，iOS 的字距（大标题 0.38 pt、正文 −0.41 pt）会让它们变松或变挤，
  全角笔画的中文最明显。

其余不变：同样的 token、同样的组件、同样的 Apple 取值。

## 安装

```toml
[dependencies]
nsh-cupertino = { version = "0.2.4", git = "https://github.com/markbang/nsh-cupertino", tag = "v0.2.4" }
```
