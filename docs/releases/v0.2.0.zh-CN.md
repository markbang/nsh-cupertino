# nsh-cupertino 0.2.0

[English](v0.2.0.md)

Cupertino 组件集的其余部分：设置页之外的浮层、选择器与控件，以及从根上修好的 0.1.0 分隔线问题。

## 安装

```toml
[dependencies]
nsh-cupertino = { git = "https://github.com/markbang/nsh-cupertino", tag = "v0.2.0" }
```

```json
{
  "rust": ["../nsh-cupertino", "."],
  "theme": "../nsh-cupertino/theme/theme.json"
}
```

## 新增

- **`Sheet`**：中、大两档，把手拖动、释放速度、仅大档变暗的遮罩，并可用遮罩、Escape、返回或拖过中档关闭。
- **`ActionSheet`**：一组 10 pt 圆角操作、另一组取消按钮、红色破坏性操作、模糊表面与安全区。
- **`AlertDialog`**：iOS 270 pt 警告框，两个按钮并排或三个以上竖排，含标准单行输入变体。
- **`ContextMenu`**：长按或右键，抬起预览、变暗页面、图标与细分隔线，Escape 关闭。
- **`Picker`**：吸附滚轮，项随滚动淡出缩小，选中带、触感与点击居中。
- **`DatePicker`**：按区域语言和周起始日的六周日历、紧凑浮层触发器、月/日/年滚轮。
- **`SegmentedControl`**：2–5 段，32 pt 轨道放在 50 pt 触控区内，白色滑块滑动。
- **`Slider`**：28 pt 滑块、着色轨道、刻度，支持键盘与读屏。
- **`TabBar`**：49 pt、25 pt 图标、10 pt 文字、数字与圆点徽标，模糊下方页面的材质。
- **`SwipeRow`**：行后的左右滑动操作、吸附打开、整滑触发并弹回，便于应用显示撤销。
- **`RefreshView`** 与 `NavPage` 的下拉：指示器随拖动落下并拉伸，刷新时固定展开。
- **材质**：`NavPage`、`NavigationBar` 与 `TabBar` 使用 `regular` 材质的半透明填充叠加 25 pt 背景模糊，浮在内容之上；没有背景模糊的平台（Linux、GPUI）只用填充色。
- 12 个演示页面与 24 张新截图，包含浮层在浅色/深色下的打开状态。

## 修复

- **分组分隔线。** 分组内除最后一行外，每行在任何显示倍率下都画出细分隔线：厚度为一台**设备像素**（`round(max(0.33 × DPR, 1)) / DPR`）。此前只写 0.33 pt，1x 屏幕会把它舍入掉，导致整段没有线。普通行、副标题、破坏性、禁用、前置图标、箭头与勾选行都适用；布局测试在 1x/2x/3x 检查矩形，截图像素测试在浅色与深色下检查实际像素。

## 未能忠实移植的部分

- **滚轮透视。** iOS 的滚轮有 3D 压缩；NSH 只能绑定缩放与透明度，无法逐行 rotateX，所以项会淡化缩小但不会翻转。
- **手机上的上下文菜单。** `nsh/base` 在触屏上以底部面板呈现，而不是预览旁的锚定菜单；桌面与 Web 上是指针处锚定，预览也在它后面。
- **Sheet 的滚动交接。** 拖动只能从把手与标题栏开始，不能像 iOS 的大档面板那样从内容顶部接管。
- **"今天"** 取自引擎墙钟的 UTC 日期，远离 UTC 的用户在午夜前后可能看到相邻日期高亮。
- **滑动删除**只上报动作；移除行与撤销条由应用完成（演示里两者都有）。
- **分段控件尺寸。** 可见轨道为 iOS 的 32 pt，外框是任务要求的 50 pt 触控区。
