# nsh-cupertino 0.2.1

[English](v0.2.1.md)

补丁版本：浮层顶层审计，以及 0.2.0 之后落地的材质跟进。

## 安装

```toml
[dependencies]
nsh-cupertino = { git = "https://github.com/markbang/nsh-cupertino", tag = "v0.2.1" }
```

## 修复

- **滚动列表中的上下文菜单。** 在滚动列表中从某一行打开的 `ContextMenu`，在 Web 上会像原生一样把抬起的预览和菜单画在页面文字之上。预览和菜单都放在 NSH 的 overlay 层，滚动内容即使裁剪也不会盖住它；锚点跟随、点击外部、Escape 与减弱动态效果都保持。
  新增 Web 回归测试：从演示的滚动列表打开菜单并按下预览，只有预览位于触发器与页面之上时按压才会命中。
- **统一顶层。** `Sheet`、`ActionSheet`、`AlertDialog` 与 `ContextMenu` 都通过库的顶层辅助函数（`overlay::layer()`）绘制，后续浮层不会误画在内联位置。

## 变更

- 浮层表面改用材质 token，而不是纯色加固定模糊：`Sheet` 与 `AlertDialog` 使用 `thick`，`ActionSheet` 的分组与取消按钮使用 `regular`，`ContextMenu` 与预览使用 `thick`；`TabBar` 保持 `regular`。
- `docs/components/*` 说明每块表面使用的材质；Sheet、操作表与警告框链接到 [issue #3](https://github.com/markbang/nsh-cupertino/issues/3)，记录 Apple 未改变的次要文字对比度。
- `NOTICE` 增加 `date_picker.dart` 的引用。
