# nsh-cupertino 0.2.1

[简体中文](v0.2.1.zh-CN.md)

A patch release: the overlay layer audit, and the materials follow-up that
landed after 0.2.0.

## Install

```toml
[dependencies]
nsh-cupertino = { git = "https://github.com/markbang/nsh-cupertino", tag = "v0.2.1" }
```

## Fixed

- **Context menus from scroll views.** A `ContextMenu` opened from a row inside
  a scrolling list paints its lifted preview and its menu above the page text on
  web, as natively. The preview and the menu are shown in NSH's overlay layer,
  which sits above scroll content whatever clips it; it follows the anchor and
  keeps press-outside, Escape and reduced-motion behaviour. A web regression
  test opens one from the demo's scrolling list and presses the preview: the
  press only reaches it while it is above the trigger and the page.
- **One top layer.** `Sheet`, `ActionSheet`, `AlertDialog` and `ContextMenu`
  all draw through the library's top-layer helper (`overlay::layer()`), so a
  future overlay cannot accidentally paint inline.

## Changed

- Overlay surfaces use the material tokens instead of solid fills with
  hard-coded blurs: `Sheet` and `AlertDialog` are the `thick` material,
  `ActionSheet` groups and its cancel button the `regular` material,
  `ContextMenu` and its preview the `thick` material. `TabBar` keeps `regular`.
- `docs/components/*` say which material each surface is, and Sheet, Action
  Sheet and Alert link [issue #3](https://github.com/markbang/nsh-cupertino/issues/3)
  for Apple's unchanged secondary-label contrast.
- `NOTICE` gains the `date_picker.dart` reference.

## Checks

`cargo fmt --check`, clippy `-D warnings`, the token tests and the separator
layout test, `nsh check`, the headless behavior tests (including the new overlay
test), and the web screenshot run with its separator pixel test.
