# nsh-cupertino 0.2.1

[简体中文](v0.2.1.zh-CN.md)

An icon set a whole app can draw from, and `Icon` for the places that are not a
control.

## What changed

- **`Icon`** — an icon on its own, with `name`, `size`, a token `tint` (`label`
  unless set) and an optional `label` for screen readers. It follows the theme,
  the appearance and the contrast setting, and its name and tint may change while
  it shows.
- **28 shapes** — inbox (`tray`), send (`paperplane`), archive, delete, flag
  (outline and filled), attachments, folders, compose and edit, schedules, reply
  and forward, refresh, links, keys, filters, failures, finished, cloud, files
  and photos, and the plain marks (`xmark`, `plus`, `ellipsis`) a bar needs.

Nothing else changed: the same tokens, the same components, the same Apple
values. The contrast decision in
[issue #3](https://github.com/markbang/nsh-cupertino/issues/3) still stands, and
an app with a 4.5:1 gate still overrides the three roles it names (or passes
`<Theme contrast="high">`).

- **`Sheet`** — a `leading` header action ("Cancel") beside the trailing one, reported by `onLeading`, for the sheets iOS opens with Cancel and Done.

- **`Sheet`** — a `leading` header action ("Cancel") beside the trailing one, reported by `onLeading`, and `scroll={false}` for content that scrolls itself.

## Install

```toml
[dependencies]
nsh-cupertino = { git = "https://github.com/markbang/nsh-cupertino", tag = "v0.2.1" }
```

```tsx
import { Icon, ListTile } from "cupertino";

<Icon name="paperclip" size={16} tint="secondary-label" />
<ListTile title="Archive" leading="archivebox" accessory="none" separator={false} />
```
