# nsh-cupertino 0.2.2

[English](v0.2.2.md)

一整套应用能直接用的图标，给"不是控件"的地方用的 `Icon`，以及"页面式面板"需要的两个 Sheet 选项。

## 变化

- **`Icon`** —— 独立的图标：`name`、`size`、token 的 `tint`（默认 `label`）和可选的
  读屏 `label`。它跟随主题、外观与对比度设置，显示中名字和颜色都可以变。
- **28 个形状** —— 收件箱（`tray`）、发送（`paperplane`）、归档、删除、标记（空心与实心）、
  附件、文件夹、写与编辑、定时、回复与转发、刷新、链接、密钥、筛选、失败、完成、云、文件与图片，
  以及栏上要用的基本符号（`xmark`、`plus`、`ellipsis`）。
- **`Sheet`** —— 头部在右侧操作之外增加 `leading`（"取消"），由 `onLeading` 上报；
  `scroll={false}` 让内容自己滚动（页面、导航栈）。

其余不变：同样的 token、同样的组件、同样的 Apple 取值。[issue #3](https://github.com/markbang/nsh-cupertino/issues/3)
里的对比度决定仍然有效。

## 安装

```toml
[dependencies]
nsh-cupertino = { git = "https://github.com/markbang/nsh-cupertino", tag = "v0.2.2" }
```
