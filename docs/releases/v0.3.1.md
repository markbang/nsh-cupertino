# nsh-cupertino 0.3.1

[简体中文](v0.3.1.zh-CN.md)

The design's type face on the platforms that are not Apple's: one family list
per platform, and iOS's tracking only where the face it was drawn for is used.

## What changed

- **The type face** — `Theme` sets the platform's family list on its root view,
  which every text inside inherits: Roboto, Noto Sans CJK SC and the system's
  last resort on Android; Segoe UI Variable Text and Microsoft YaHei UI on
  Windows; Inter, Cantarell and DejaVu Sans on Linux; `-apple-system` first on
  the web. Apple platforms name none: SF Pro (PingFang for Chinese) is the face
  the type scale was drawn for.
- **The tracking** — `tokens::tracking(style)` is the design's value on the
  Apple platforms and none elsewhere. Roboto and Noto carry their own spacing;
  iOS's tracking (0.38 pt on a large title, −0.41 pt on body text) loosens or
  crowds them, and Chinese, whose glyphs are full-width, shows it most.

Nothing else changed: the same tokens, the same components, the same Apple
values.
