# 骨架屏

列表仍在加载时的灰色占位：每行是一个 72 pt 的槽位，含 46 pt 头像、两行文字与末端的小胶囊，画在抬起的表面上，
换成真实内容时位置不动。形状取自 Cohub Mobile 的 `LoadingRows`。

| TSX | Rust | 类型 | 默认 | |
| --- | --- | --- | --- | --- |
| `rows` | `.rows(..)` | `number` | `3` | 画几行 |

说明

- 占位色为 `system-gray5`，两种外观下都是抬起控件的表面色。
- 它不做动画；会呼吸的加载指示由调用方自行添加。
- 标题行占文字列的 58%、68%、78%，副标题占 38% 或 53%，按行轮换，与 Cohub Mobile 一致。

## 无障碍

- 它是标为 "Loading" 的进度条。内容到达后替换为真实内容。
